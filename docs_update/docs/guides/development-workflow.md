# 개발 워크플로우 및 품질 게이트

## 신규 기능 개발 5단계 프로세스

### 1단계: 현장 시나리오 정의
**목적**: 실제 작업 흐름 이해 및 문서화

**산출물**:
- 공정 단계 명시 (어느 공정?)
- 작업자 역할 명시 (누가?)
- 작업 내용 명시 (무엇을?)
- 작업 목적 명시 (왜?)
- 물리적 동선 다이어그램
- 팔레트/LOT/태그 상태 변화

**체크리스트**:
- [ ] 실제 공정 용어 사용
- [ ] 현장 담당자와 용어 확인
- [ ] 작업 동선이 물리적으로 가능한가?
- [ ] 예외 상황 고려 (장애, 오류 등)

---

### 2단계: 흐름도/상태 다이어그램 설계
**목적**: 시스템 동작 시각화

**산출물**:
- 팔레트 상태 전이 다이어그램
- LOT 생명주기 다이어그램
- 공정 IN/OUT 흐름도
- 예외 처리 흐름 (Hold/Defect/재작업)
- 양방향 추적성 경로 확인

**체크리스트**:
- [ ] 모든 상태 전환이 헌법 규칙 준수
- [ ] 정방향 추적 가능 (원자재 → 제품)
- [ ] 역방향 추적 가능 (제품 → 원자재)
- [ ] 예외 상황 복구 경로 존재
- [ ] 팔레트 빠른 회수 원칙 준수

---

### 3단계: 테스트 케이스 정의
**목적**: 검증 가능한 시나리오 작성

**필수 테스트 케이스**:
1. **정상 시나리오** (Happy Path)
   - 정상 흐름 완전 실행
   - 예상 결과 명시
   
2. **예외 시나리오** (최소 1개 이상)
   - FIFO 위반
   - 오투입 (잘못된 공정)
   - 네트워크 장애
   - RFID 태그 읽기 실패

**테스트 데이터**:
- 실제 아진산업 공정 흐름 반영
- 원자재 입고 → 샤링 → 프레스 → 조립 → 완제품 출하

**체크리스트**:
- [ ] Given-When-Then 형식으로 작성
- [ ] 예상 결과 명시
- [ ] 테스트 데이터 준비
- [ ] 통합 테스트는 RFID 스캔 시퀀스 시뮬레이션

---

### 4단계: 구현 및 자기 점검
**목적**: 코드 작성 및 1차 검증

**구현 가이드라인**:
- **API 설계**: 팔레트를 주요 리소스로 하는 RESTful 설계
- **오류 처리**: 작업자에게 적합한 실행 가능한 메시지
- **성능**: 태그 스캔 → 피드백 500ms 이내
- **로깅**: 모든 상태 변경 이벤트 기록

**자기 점검**:
- [ ] 정의된 테스트 케이스 모두 통과
- [ ] 코드가 현장 시나리오와 일치
- [ ] 에러 메시지가 명확하고 실행 가능
- [ ] 양방향 추적성 유지
- [ ] 헌법 원칙 준수

---

### 5단계: 현장 담당자 데모 및 피드백 반영
**목적**: 실제 사용성 검증

**데모 준비**:
- 실제 환경과 유사한 설정
- 실제 공정 용어 사용
- 작업자가 직접 조작 가능

**확인 사항**:
- [ ] 실제 공정 용어와 일치하는가?
- [ ] 작업자가 사용하기 편한가?
- [ ] 교육 없이도 이해 가능한가?
- [ ] 최소 클릭/스캔으로 업무 완료 가능한가?

**피드백 반영**:
- 즉시 반영 가능한 것은 바로 수정
- 큰 변경은 재검토 및 재승인

---

## PR/코드 리뷰 필수 확인 항목

### 1. 헌법 준수 확인
- [ ] 팔레트/LOT/태그 상태 전이가 헌법 규칙과 일치하는가?
- [ ] 10가지 핵심 원칙을 위반하지 않는가?

### 2. 추적성 확인
- [ ] 정방향 추적 경로가 끊기지 않는가? (원자재 → 제품)
- [ ] 역방향 추적 경로가 끊기지 않는가? (제품 → 원자재)
- [ ] 필수 키(코일 번호, LOT 번호, 팔레트 번호, EPC)를 삭제/재사용하지 않는가?

### 3. 현장 적합성 확인
- [ ] 화면/API가 실제 공정 용어와 일치하는가?
- [ ] 작업 동선이 물리적으로 가능한가?
- [ ] 최소 클릭/스캔 원칙을 준수하는가?

### 4. 성능 확인
- [ ] 태그 스캔부터 피드백까지 500ms 이내 완료 가능한가?
- [ ] 병목 지점은 없는가?

### 5. 문서화 확인
- [ ] RFID 리더기 통합 프로토콜 문서화
- [ ] 상태 기계 전환 문서화
- [ ] API 명세 문서화

## 배포 전 체크리스트

### 핵심 시나리오 테스트
- [ ] **전 공정 시뮬레이션** 최소 1회 이상
  - 원자재 입고
  - 샤링 공정
  - 프레스 공정
  - 조립 공정
  - 완제품 출하

### 추적성 테스트
- [ ] **정방향 추적** 1회 이상 검증
  - 특정 코일 번호 입력
  - 해당 코일로 생산된 모든 제품 확인
  
- [ ] **역방향 추적** 1회 이상 검증
  - 특정 완제품 선택
  - 사용된 모든 LOT 및 원자재 확인

### 예외 상황 테스트
- [ ] FIFO 위반 시나리오 (경고 + Hold)
- [ ] 오투입 시나리오 (차단)
- [ ] 네트워크 장애 복구
- [ ] RFID 태그 읽기 실패 처리

### 배포 준비
- [ ] 롤백 방안 문서화
- [ ] 변경 이력 정리 (Change Log)
- [ ] 현장 공지 준비
- [ ] 간단 매뉴얼/스크린샷 준비
- [ ] 담당자 승인 획득

## 지속적 개선

### 주기적 검토
- 월 1회: 현장 담당자 피드백 수렴
- 분기 1회: 헌법 업데이트 필요성 검토
- 반기 1회: 전체 시스템 아키텍처 리뷰

### 성능 모니터링
- 태그 스캔 응답 시간
- API 응답 시간
- 데이터베이스 쿼리 성능
- RFID 리더기 오류율

### 사용성 개선
- 작업자 오류 패턴 분석
- 자주 사용하는 기능 최적화
- 불필요한 단계 제거
