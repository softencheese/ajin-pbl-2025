# 웹 애플리케이션 상세 명세서

> **목적**: RFID 물류 추적 시스템 웹 애플리케이션 구현 명세
> **대상**: Speckit Plan - 웹 애플리케이션 개발

---

## 1. 웹 애플리케이션 역할

### 1.1 개요
- 공정 배치 및 RFID 리더기 매핑 설정
- 마스터 데이터 등록 및 관리
- 실시간 공정 모니터링
- 추적성 조회 (드릴다운 UI)
- 재고 현황 및 이력 조회
- 생산 실적 리포트

### 1.2 기술 스택 권장
- **프론트엔드**: React.js 18+ / Vue.js 3+
- **UI 프레임워크**: Ant Design / Material-UI / Vuetify
- **상태 관리**: Redux / Zustand / Vuex / Pinia
- **차트**: Chart.js / ECharts / Recharts
- **실시간 통신**: Socket.io-client / EventSource (SSE)
- **빌드 도구**: Vite / Next.js

## 3. 화면별 상세 명세

### 3.1 대시보드

#### 3.1.1 목적
- 전체 시스템 현황 한눈에 파악
- 주요 지표 요약 표시

#### 3.1.2 구성 요소

**KPI 카드 (4개)**:
```
┌─────────────┐ ┌─────────────┐ ┌─────────────┐ ┌─────────────┐
│ 활성 팔레트 │ │ 재고 수량   │ │  금일 생산  │ │ 리더기 상태 │
│    125개    │ │  3,450 EA   │ │   890 EA    │ │  12/13 연결 │
└─────────────┘ └─────────────┘ └─────────────┘ └─────────────┘
```

**공정별 현황 (차트)**:
- 막대 그래프: 공정별 활성 팔레트 수
- 색상: 상태별 (Producing: 파랑, Consuming: 주황, Stock: 초록)

**최근 이벤트 타임라인**:
```
┌─────────────────────────────────────────────────────┐
│ 최근 이벤트 (실시간)                   [전체 보기]  │
├─────────────────────────────────────────────────────┤
│ 09:30:15 PLT-001 Stock → Consuming (프레스 IN)     │
│ 09:29:45 PLT-002 Producing → Stock (프레스 OUT)    │
│ 09:29:10 ⚠️  FIFO 위반 경고 (PLT-003)              │
│ 09:28:30 PLT-004 Empty → Producing (조립 IN)       │
└─────────────────────────────────────────────────────┘
```

**재고 현황 요약**:
- 전체 재고 수량
- 3일 이상 오래된 재고 수량 (경고)
- 5일 이상 오래된 재고 수량 (위험)

#### 3.1.3 실시간 업데이트
- WebSocket 또는 SSE로 1초마다 업데이트
- 새 이벤트 발생 시 애니메이션 효과

### 3.2 공정 배치 관리

#### 3.2.1 목적
- RFID 리더기 포트와 공정/위치 매핑
- 공정 순서 정의
- 리더기 연결 상태 모니터링

#### 3.2.2 리더기 목록 화면
```
┌─────────────────────────────────────────────────────┐
│ 공정 배치 관리                                      │
│                                                     │
│ [미등록 리더기 (1)] ──────────────────────────────  │
│   📡 READER_NEW_01 [등록하기]                      │
│                                                     │
│ [샤링 400T] ──────────────────────────────────────  │
│   📡 COM3 (OUT) ✅ 연결됨   [편집] [삭제]          │
│   📡 COM4 (HOLD) ✅ 연결됨  [편집] [삭제]          │
│                                                     │
│ [프레스 1500T] ───────────────────────────────────  │
│   📡 192.168.1.100:9001 (IN) ✅ 연결됨 [편집]      │
│   📡 192.168.1.100:9002 (OUT) ❌ 끊김   [편집]     │
│                                                     │
│ [조립] ───────────────────────────────────────────  │
│   📡 192.168.1.101:9001 (IN) ✅ 연결됨  [편집]     │
│   📡 192.168.1.101:9002 (OUT) ✅ 연결됨 [편집]     │
│   📡 192.168.1.101:9003 (FINISH) ✅ 연결됨 [편집]  │
│                                                     │
└─────────────────────────────────────────────────────┘
```

#### 3.2.3 리더기 등록(매핑) 모달
**진입**: 미등록 리더기의 `[등록하기]` 버튼 클릭

**필드**:
- 포트 이름 (읽기 전용): `READER_NEW_01`
- 공정* (드롭다운): 샤링, 프레스, 조립, 출하
- 위치 타입* (드롭다운): IN, OUT, HOLD, DEFECT, FINISH
- 설명 (텍스트): 자유 입력
- 활성 상태 (체크박스): 기본 체크됨

**검증**:
- 포트 이름 사용 중인 것이 있을 경우 중복 불가
- 필수 필드 입력 확인

#### 3.2.4 공정 순서 정의
- 드래그 앤 드롭으로 공정 순서 변경
- 순서 변경 시 `process_order` 자동 업데이트

### 3.3 마스터 데이터 관리

#### 3.3.1 공통 UI 패턴
**목록 화면**:
- 검색: 상단 검색바
- 필터: 드롭다운 (카테고리별)
- 정렬: 컬럼 헤더 클릭
- 페이징: 하단 페이지네이션 (20개/페이지)
- 액션: [추가], [수정], [삭제]

**등록/수정 화면**:
- 모달 또는 사이드 패널
- 폼 검증: 실시간 에러 표시
- 저장 성공 시: 토스트 알림 + 목록 새로고침

#### 3.3.2 원자재 관리
**목록 컬럼**:
- 코일 번호
- 원자재명
- 공급업체
- 입고일자
- QC 상태 (합격/불합격)
- 사용 여부 (사용됨/미사용)

**등록 필드**:
- 코일 번호* (텍스트, UNIQUE)
- 원자재명* (텍스트)
- 공급업체 (텍스트)
- 입고일자* (날짜 선택)
- QC 합격 여부 (체크박스)

#### 3.3.3 품번 관리
**목록 컬럼**:
- 품번
- 품명
- 차종
- 조립품 여부
- 완제품 여부

**등록 필드**:
- 품번* (텍스트, UNIQUE)
- 품명* (텍스트)
- 품목 사양 (텍스트)
- 차종 (텍스트)
- 조립품 여부 (체크박스)
- 완제품 여부 (체크박스)

#### 3.3.4 공정 관리
**목록 컬럼**:
- 공정 코드
- 공정명
- 공정 순서
- 생산 라인

**등록 필드**:
- 공정 코드* (텍스트, UNIQUE)
- 공정명* (텍스트)
- 공정 순서* (숫자)
- 생산 라인 (텍스트)

#### 3.3.5 팔레트 관리
**목록 컬럼**:
- 팔레트 번호
- RFID EPC
- 연결된 LOT
- 상태
- 현재 공정

**등록 필드**:
- 팔레트 번호* (텍스트, UNIQUE)
- RFID EPC* (텍스트, UNIQUE)

**LOT 연결**:
- 팔레트 선택 → [LOT 연결] 버튼 → LOT 검색 모달

#### 3.3.6 LOT 관리
**탭 구성**:
- 중간품 LOT
- 조립품 LOT

**중간품 LOT 등록 필드**:
- LOT 번호* (텍스트, UNIQUE)
- 품번* (드롭다운, 중간품만)
- 공정* (드롭다운)
- 원자재* (드롭다운, 코일 번호)
- 수량* (숫자)
- 생산일자* (날짜 선택)
- 작업자 (텍스트)
- QC 합격 여부 (체크박스)

**조립품 LOT 등록 필드**:
- LOT 번호* (텍스트, UNIQUE)
- 품번* (드롭다운, 조립품만)
- 조립일자* (날짜 선택)
- 수량* (숫자)
- 작업자 (텍스트)
- QC 합격 여부 (체크박스)

**조립품 구성 요소 추가**:
- 조립품 LOT 선택 → [구성 요소 추가] 버튼
- 필드: 중간품 LOT / 하위 조립품 LOT (하나 선택), 단위당 수량, 총 소비 수량
